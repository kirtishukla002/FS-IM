# FS-IM
“Fuzzy Signed Influence Maximization in Signed Social Networks"
This repository contains the official implementation of the paper
"Fuzzy-based Diversified Signed Influence
Maximization on Online Social Networks" (Kirti Shukla, Amit anerjee, and Shashank Sheshar Singh, South Asian University, 28-OCT-2026).

We propose a fuzzy-signed independent cascade model (FS-IC) that captures conformity, reactance, and structural balance in signed social networks,
and seed selection algorithms that maximize net positive influence under a budget k.

The repository includes:
- the FS-IC diffusion model and seed selection algorithms (algorithms.py)
- all parameter settings (settings.py)
- dataset loading and sign/weight assignment (dataset.py)
- instructions to reproduce the paper's results (see "How to run")
